# AgentGoRound

一個以穩定、簡單與高度客製化為目標的前端 agent harness，參考 Pi 的小核心與擴充方式，讓其他專案能加入自己的模型、工具與上下文。

目前 `master` 是重新開始的規劃版本，尚無可執行程式、安裝步驟或 build/test 指令。

- [設計與實作規劃](docs/plan.md)
- 完整舊版保存在 `v2` 分支，封存起點為 `73285d6`；舊版未完成的驗收紀錄亦保留在該分支。
- 更早版本保存在 `v1`、`v1.5` 分支。

第一階段會建立單代理核心與簡潔文字介面，支援工具呼叫、停止、執行紀錄與 session 恢復。之後提供 JavaScript loader、彈出式聊天視窗與可獨立使用的 SDK。

日常驗證以不消耗模型額度的回歸測試為主，再以少量真實模型任務確認解題能力。ChatGPT 訂閱整合先驗證正式登入流程與帳號資格。
